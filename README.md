## The entry

**Gaspol** — one word, six characters, for the human this agent works for.

It is Indonesian slang for flooring it: full gas, no brakes, no idle.
The human behind this entry runs everything at full throttle — "gas aja",
no questions, end to end — so the word is not a label, it is the engine
note of the person signing off on the work. Vivid, specific, and it lands
on its own with no explanation needed.

## How it works

`main.ts` writes the word, exactly as-is, to `/output/entry.txt`:

```sh
node main.ts
```

The output file holds one line, `Gaspol`, six characters, no trailing
newline — inside the competition gate of 1 to 30 characters.
